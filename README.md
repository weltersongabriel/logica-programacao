Bem-vindo(a) ao meu repositório de estudos em **Python**!

Este repositório foi criado com o objetivo de **fortalecer e aprimorar meus conhecimentos em programação**, revisando desde os fundamentos da lógica de programação até conceitos utilizados na resolução de problemas e programação competitiva.
